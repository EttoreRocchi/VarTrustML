=====
train
=====

Train a single model with hyperparameter tuning.

Synopsis
--------

.. code-block:: bash

   vartrustml train DATA [OPTIONS]

Description
-----------

Train a single machine learning model with cross-validated hyperparameter tuning. Supports:

- Multiple model types
- Optional holdout test set
- Model calibration
- Threshold optimization
- HTML report generation

Examples
--------

Basic Usage
^^^^^^^^^^^

.. code-block:: bash

   # Train XGBoost (default)
   vartrustml train data/HG002.csv -t state

   # Train specific model
   vartrustml train data/HG002.csv -t state --model "Random Forest"

   # With custom CV folds
   vartrustml train data/HG002.csv -t state \
     --model "XGBoost" \
     --cv-folds 10 \
     --scoring balanced_accuracy

With Test Set
^^^^^^^^^^^^^

.. code-block:: bash

   # Internal holdout split
   vartrustml train data/HG002.csv -t state \
     --model "Random Forest" \
     --test-size 0.2

   # External test dataset
   vartrustml train data/HG002.csv -t state \
     --model "XGBoost" \
     --test-data data/REACH.csv

With Calibration (HTML Report Generated by Default)
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

.. code-block:: bash

   # HTML report is generated by default
   vartrustml train data/HG002.csv -t state \
     --model "XGBoost" \
     --test-size 0.2 \
     --calibrate-model \
     --calibration-method isotonic

   # To disable HTML report generation
   vartrustml train data/HG002.csv -t state \
     --model "XGBoost" \
     --test-size 0.2 \
     --no-html-report

With Threshold Optimization
^^^^^^^^^^^^^^^^^^^^^^^^^^^

.. code-block:: bash

   # With threshold optimization (uses Youden's J statistic)
   vartrustml train data/HG002.csv -t state \
     --model "XGBoost" \
     --test-size 0.2 \
     --optimize-threshold \
     --threshold-method auto

   # Combined with calibration (recommended)
   vartrustml train data/HG002.csv -t state \
     --model "XGBoost" \
     --test-size 0.2 \
     --calibrate-model \
     --optimize-threshold

Options Reference
-----------------

Data Options
^^^^^^^^^^^^

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Option
     - Description
   * - ``-t, --target TEXT``
     - Target column name (**required**)
   * - ``--features TEXT``
     - Comma-separated feature columns
   * - ``--continuous TEXT``
     - Continuous columns to scale (comma-separated list or path to .txt file)
   * - ``--categorical TEXT``
     - Categorical columns (comma-separated list or path to .txt file). If provided without ``--continuous``, continuous columns are inferred by exclusion. Categorical columns are not scaled, but they do receive a most-frequent imputer whenever ``--nan-strategy`` is an impute strategy.
   * - ``--test-data PATH``
     - External test dataset, resolved against its own path. Its rows are scored as given, without de-duplication, so the reported support matches the file.
   * - ``--test-size FLOAT``
     - Internal test split ratio

Input/Output Options
^^^^^^^^^^^^^^^^^^^^

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Option
     - Description
   * - ``DATA``
     - Path to training dataset (required)
   * - ``-o, --output-dir PATH``
     - Output directory (default: ``results/trained_model``)

Model Options
^^^^^^^^^^^^^

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Option
     - Description
   * - ``-m, --model TEXT``
     - Model to train (default: ``XGBoost``)
   * - ``--param-config FILE``
     - Custom parameter grid JSON

Cross-Validation Options
^^^^^^^^^^^^^^^^^^^^^^^^

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Option
     - Description
   * - ``--cv-folds INT``
     - Number of CV folds (default: 5)
   * - ``--seed INT``
     - Random seed (default: 42)
   * - ``--scoring TEXT``
     - Sklearn scoring metric (default: ``roc_auc``)

Calibration Options
^^^^^^^^^^^^^^^^^^^

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Option
     - Description
   * - ``--calibrate-model``
     - Enable probability calibration
   * - ``--calibration-method TEXT``
     - ``isotonic`` or ``sigmoid``
   * - ``--calibration-cv INT``
     - Calibration CV folds

Threshold Optimization Options
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Option
     - Description
   * - ``--optimize-threshold``
     - Enable threshold optimization using Youden's J statistic
   * - ``--threshold-method TEXT``
     - ``oof`` (out-of-fold), ``cv`` (per-fold average), or ``auto``

Report Options
^^^^^^^^^^^^^^

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Option
     - Description
   * - ``--no-html-report``
     - Disable HTML report generation (enabled by default)
   * - ``--html-path TEXT``
     - Custom HTML report path (default: ``train_report.html``)

System Options
^^^^^^^^^^^^^^

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Option
     - Description
   * - ``--n-jobs INT``
     - Parallel jobs (-1 for all cores)
   * - ``--quiet``
     - Suppress output
   * - ``--dry-run``
     - Preview without running

Output Files
------------

::

   results/trained_model/
   ├── trained_model.joblib          # Serialized model
   ├── training_report.csv           # CV results
   ├── best_parameters.json          # Best hyperparameters
   ├── predictions.csv               # Predictions (if enabled)
   └── training_report.html          # Interactive report (if enabled)
