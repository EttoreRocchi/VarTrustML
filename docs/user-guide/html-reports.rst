============
HTML Reports
============

VarTrustML writes an interactive HTML report, built on Plotly, alongside the CSV outputs of every experiment.

Overview
--------

The report gathers the model comparison, feature importances, normalised
confusion matrices and per-fold score distributions into charts you can zoom
and pan. Everything is inlined into one HTML file with no external assets, so
it can be attached to an email or dropped into supplementary material as is.

Report Types
------------

Model Comparison Reports
^^^^^^^^^^^^^^^^^^^^^^^^

Generated by ``HTMLCompareReporter`` for comparing multiple models:

- Experiment overview with CV configuration
- Model performance comparison charts
- Performance heatmap across all metrics
- Confusion matrices for each model
- Feature importance by model
- Cross-validation box plots
- Bootstrap confidence intervals (bias-corrected and accelerated)
- Paired statistical comparison (McNemar / DeLong) with ROC/PR dominance figure

Training Reports
^^^^^^^^^^^^^^^^

Generated by ``HTMLTrainReporter`` for single model training:

- Training overview with model configuration
- Hyperparameter tuning results
- Test set performance metrics
- Confusion matrix
- Feature importance

HTML Report Generation
----------------------

CLI
^^^

**For Model Comparison:**

.. code-block:: bash

   # Basic usage (HTML report generated automatically)
   vartrustml compare-models HG002.csv -t state

   # Suppress HTML report generation
   vartrustml compare-models HG002.csv -t state --no-html-report

   # Custom output path
   vartrustml compare-models HG002.csv -t state --html-path "my_experiment.html"

**For Single Model Training:**

.. code-block:: bash

   # HTML report is generated by default
   vartrustml train data/HG002.csv -t state --model "XGBoost"

   # Custom output path and with test set
   vartrustml train data/HG002.csv -t state \
     --model "XGBoost" \
     --test-size 0.2 \
     --html-path "training_report.html"

Python API
^^^^^^^^^^

.. code-block:: python

   from vartrustml import ExperimentConfig, CrossValidationPipeline

   config = ExperimentConfig(
       generate_html_report=True,
       html_report_path="report.html",
       models_to_use=["XGBoost", "Random Forest"]
   )

   pipeline = CrossValidationPipeline(config)
   results, _ = pipeline.run_cross_validation(df, "HG002")
   # Report automatically generated at results/HG002/report.html

Configuration File
^^^^^^^^^^^^^^^^^^

.. code-block:: json

   {
     "generate_html_report": true,
     "html_report_path": "experiment_report.html",
     "models_to_use": ["XGBoost", "Random Forest", "MLP"]
   }

Report Structure
----------------

Experiment Overview
^^^^^^^^^^^^^^^^^^^

Displays key configuration parameters:

- VarTrustML version and timestamp
- Random seed
- CV fold configuration (outer/inner)
- HPO method (grid/optuna)
- Calibration settings
- Bootstrap CI configuration
- Models trained
- Dataset statistics

Model Performance Comparison
^^^^^^^^^^^^^^^^^^^^^^^^^^^^

Interactive bar chart showing:

- Primary metric (AUROC by default)
- Performance for all models
- Error bars (standard deviation)
- Hover information
- Clickable legend

Features:

- Zoom and pan
- Download as PNG
- Toggle models on/off

Cross-Validation Box Plots
^^^^^^^^^^^^^^^^^^^^^^^^^^

Visualizes metric distribution across folds:

- Per-model box plots
- Outlier identification
- Median and quartiles
- Whiskers showing data spread

Confusion Matrices
^^^^^^^^^^^^^^^^^^

Heatmap visualization:

- Normalized values
- Color-coded cells
- Hover for exact counts
- Separate matrix per model

Feature Importance
^^^^^^^^^^^^^^^^^^

Bar charts showing:

- Top N features per model
- Relative importance scores
- Comparison across models

Opening Reports
---------------

After generation, open the HTML file in any modern browser:

.. code-block:: bash

   # macOS
   open results/HG002/report.html

   # Linux
   xdg-open results/HG002/report.html

   # Windows
   start results/HG002/report.html
